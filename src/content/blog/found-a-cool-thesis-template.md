As you might have already **guessed** from the title, I am now using a new PhD thesis template found on this GitHub repository: [UCDThesis](https://github.com/aonghus/UCDThesis). To be clear, it is not an official UCD template (I haven't found one), but I really like the aesthetic. All the description and installation details are explained in the Readme, so I won’t repeat them here.

The creator of this GitHub repository is **Aonghus Lawlor**, an assistant professor in the School of Computer Science at UCD. However, the original template comes from **André Miede**, a computer scientist at Saarland University of Applied Sciences ([miede.de](https://miede.de/)). I found his website quite quirky; more importantly, if you do use the template, he mentions he "would appreciate a postcard." His website lists all the postcards he has received over the years and shows some stats about them, which I thought was a really cool touch.

If I am mistaken and there **is** a proper template provided by the School of Mathematics & Statistics, please let me know in the comments! It would be good to know for sure before I actually submit. Also, if you’re using a different template yourself, feel free to share a link below.
